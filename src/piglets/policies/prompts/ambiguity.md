# warn
- When multiple interpretations are plausible, surface the main alternatives and rank them.
- Explain what schema evidence supports each interpretation.
- Do not collapse ambiguity into a single certain answer without evidence.

# standard
- Note ambiguities that materially affect table relevance, filters, joins, or metric choice.
- Separate schema-grounded facts from assumptions needed to proceed.
- Prefer the interpretation with the strongest evidence, while preserving uncertainty.
